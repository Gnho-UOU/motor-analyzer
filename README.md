# MotorAnalyzer v0.5.16

## AI 코딩을 활용한 3상 유도전동기 운전점·기동·열 특성 시뮬레이터

MotorAnalyzer는 3상 유도전동기의 정격 운전, 기동 특성, 부하 모델, 토크-속도 곡선, 권선 온도 상승, 운전 상태 경고를 시각적으로 확인할 수 있도록 제작한 교육용 전동기 해석 프로그램입니다.

React, Vite, Electron을 기반으로 개발하였으며, OpenAI ChatGPT와 Codex를 활용하여 기능 설계, 코드 구현, 오류 수정, 시뮬레이션 구조 개선을 반복하며 제작하였습니다.

> ⚠️ **실행 전 필독**
>
> 소스코드로 실행하려면 `node_modules` 폴더가 필요합니다. GitHub 저장소에는 용량 문제로 `node_modules`를 포함하지 않으므로, 소스코드 실행 시 반드시 [`npm install` 후 개발 서버 실행](#source-run)을 먼저 진행해야 합니다.
>
> 별도 개발환경 없이 바로 실행하려면 [`Windows 실행 파일 다운로드`](#windows-download) 항목에서 `Setup` 또는 `Portable` 버전을 다운로드하여 실행하면 됩니다.
>
> `Portable` 버전은 설치 없이 바로 실행할 수 있지만, 더 안정적인 실행과 바로가기 생성, 앱 등록 등을 위해서는 [`Setup 버전 설치`](#setup-install)를 권장합니다.
>
> 바로 실행만 해보고 싶다면 [`Portable 버전 바로 실행`](#portable-run)을 참고하면 됩니다.

## 1. 프로젝트 개요

본 프로젝트는 전기전자공학에서 다루는 3상 유도전동기의 핵심 개념을 단순 공식 계산이 아니라, 실제 프로그램 형태의 시뮬레이션으로 확인하기 위해 제작되었습니다.

사용자는 Wizard를 통해 전동기 종류, 제조사, 정격 사양, 부하 모델, 시험 목적을 설정할 수 있으며, 이후 Dashboard에서 전동기의 운전점, 기동 과정, 토크-속도 특성, 전류 파형, 열 상태, 운전 경고를 확인할 수 있습니다.

주요 해석 대상은 다음과 같습니다.

- 3상 유도전동기의 회전자계 형성
- 동기속도와 회전자속도
- 슬립과 전자기 토크
- 정격부하 운전점
- 기동 특성
- 부하 모델별 기동 차이
- 저전압, 과부하, 고슬립 운전
- 권선 온도 상승 및 냉각 효과
- 운전 상태 경고
- PDF 리포트 생성
- Windows 실행 파일 패키징

> 본 프로그램은 교육용 시뮬레이터입니다. 실제 산업 현장의 전동기 선정, 보호계전기 설정, 열해석, 기동 검토, 설비 설계에는 반드시 제조사 데이터시트, 실제 시험 데이터, 현장 조건, 관련 표준을 함께 검토해야 합니다.

## 2. 개발 목적

MotorAnalyzer의 목적은 3상 유도전동기의 이론을 시각적으로 이해하고, 전동기 운전 조건이 바뀔 때 속도, 토크, 슬립, 부하, 온도, 경고 상태가 어떻게 변하는지 확인하는 것입니다.

특히 다음 내용을 교육적으로 확인할 수 있도록 구성했습니다.

- 정격전압, 정격주파수, 극수에 따른 동기속도 계산
- 명판값을 이용한 정격토크 및 정격슬립 계산
- Thevenin 등가회로 기반 유도전동기 토크 계산
- 부하토크와 전동기 토크가 만나는 운전점 분석
- 정격부하 운전과 정지 상태 기동의 차이
- 정토크 부하, 팬·펌프 부하, 선박 추진 부하의 차이
- 기동 중 속도, 슬립, 토크 변화
- 손실 및 권선온도 상승의 교육용 추정
- 운전 조건에 따른 경고 및 판정

### 3.4 운전조건 프리셋

현재 지원하는 프리셋은 다음과 같습니다.

- 무부하 운전
- 정격부하 운전
- 과부하 운전
- 저전압 운전
- 고슬립 운전
- 사용자 설정

프리셋은 고정된 수치가 아니라, 현재 선택된 전동기 정격값을 기준으로 자동 생성됩니다.

```text
무부하     ≈ 정격토크의 5%
정격부하   = 정격토크의 100%
과부하     ≈ 정격토크의 150%
저전압     = 정격전압의 80%
고슬립     ≈ 정격토크의 150~180%
```

### 3.5 부하 모델

MotorAnalyzer는 부하의 종류에 따라 속도별 부하토크가 다르게 변하도록 구성되어 있습니다.

#### 정토크 부하

속도와 관계없이 부하토크가 거의 일정한 부하입니다.

```text
TL(speed) = TL_rated
```

컨베이어, 압축기, 일부 기계 부하를 단순화할 때 사용할 수 있습니다.

#### 팬·펌프 부하

속도가 증가할수록 부하토크가 제곱에 비례하여 증가하는 부하입니다.

```text
TL(speed) = TL_rated × (speed / ratedSpeed)^2
```

팬, 펌프, 블로어 부하를 설명할 때 사용할 수 있습니다.

#### 선박 추진 부하

프로펠러 부하처럼 속도 증가에 따라 부하토크가 더 강하게 증가하는 형태입니다.

```text
TL(speed) = TL_rated × (speed / ratedSpeed)^2.5
```

#### 사용자 정의 부하

사용자가 입력한 조건을 기준으로 부하토크를 직접 설정할 수 있습니다.

### 3.6 정격부하 운전과 기동 시뮬레이션 분리

현재 버전에서는 정격부하 운전과 기동 시뮬레이션을 구분합니다.

정격부하 운전은 정상 운전점에서의 해석입니다.

```text
Nr ≈ ratedSpeed
slip ≈ ratedSlip
Te ≈ TL
```

반면 START 버튼을 누르면 전동기는 0 rpm에서 기동을 시작합니다.

이때 부하모델에 따라 초기 부하토크가 다르게 적용됩니다.

```text
정토크 부하      → 0 rpm에서도 큰 부하토크
팬·펌프 부하    → 0 rpm에서 부하토크 거의 0
선박 추진 부하  → 0 rpm에서 부하토크 거의 0
```

따라서 정격부하 운전이 가능하더라도, 정토크 부하를 정지 상태에서 바로 기동하는 경우에는 기동 실패가 발생할 수 있습니다.

### 3.10 토크-속도 특성 곡선

토크-속도 특성 곡선에서는 다음 정보를 확인할 수 있습니다.

- 전동기 토크 곡선
- 부하토크 곡선
- 기동토크 지점
- 최대토크 지점
- 운전점
- 정격 조건 기준 곡선
- Thevenin 등가회로 파라미터

운전점은 전동기 토크와 부하토크가 만나는 지점으로, 해당 지점에서 회전자 속도와 슬립이 결정됩니다.

### 3.11 기동 특성 그래프

기동 특성 그래프에서는 START 이후 시간에 따른 다음 변화를 확인할 수 있습니다.

- 회전자 속도 Nr(t)
- 부하토크 TL(t)
- 전자기 토크 Te(t)
- 슬립 s(t)

기동 시뮬레이션은 다음의 단순 동역학 모델을 기반으로 합니다.

```text
J × dω/dt = Te - TL - Bω
```

---

### 3.12 3상 전류 파형

A상, B상, C상 전류가 서로 120도 위상차를 갖는 것을 그래프로 확인할 수 있습니다.

```text
ia = Im sin(ωt)
ib = Im sin(ωt - 2π/3)
ic = Im sin(ωt - 4π/3)
```

이는 3상 전류가 회전자계를 형성하는 원리를 시각적으로 보여주기 위한 교육용 모델입니다.

---

### 3.13 등가회로 파라미터

유도전동기의 Thevenin 등가회로 해석을 위해 다음 파라미터를 사용합니다.

- R1: 고정자 저항
- R2': 회전자 저항
- X1: 고정자 누설 리액턴스
- X2': 회전자 누설 리액턴스
- Xm: 자화 리액턴스
- Rc: 철손 저항

정격값 기반 교육용 추정 모드에서는 정격 슬립 지점에서 전자기 토크가 정격토크와 일치하도록 토크 곡선을 보정합니다.

> 실제 제품의 등가회로 파라미터는 무부하 시험, 구속 시험, 제조사 데이터시트 등을 통해 얻어야 합니다.

### 3.14 권선온도 및 열 모델

MotorAnalyzer는 손실과 냉각을 고려한 단순 열 모델을 포함합니다.

기본 열 모델은 다음과 같은 열평형 개념을 사용합니다.

```text
dT/dt = (Ploss - Qcool) / Cth
```

여기서 냉각은 다음과 같이 단순화됩니다.

```text
Qcool = (T - Tambient) / Rth_effective
```

또한 실제 전동기에는 팬과 프레임 방열이 존재하므로, 회전자 속도에 따라 냉각 효과가 달라지도록 구성했습니다.

```text
speedRatio = rotorSpeed / ratedSpeed
fanCoolingFactor = naturalCooling + forcedCooling × speedRatio^fanExponent
```

이를 통해 정격 운전 중 권선온도가 계속 무한히 상승하지 않고, 손실과 냉각이 평형을 이루는 정상상태 온도에 접근하도록 구성했습니다.

## 4. 사용한 주요 이론

### 4.1 동기속도

```text
Ns = 120f / P
```

- Ns: 동기속도 [rpm]
- f: 전원 주파수 [Hz]
- P: 극수

---

### 4.2 슬립

```text
s = (Ns - Nr) / Ns
```

- s: 슬립
- Ns: 동기속도 [rpm]
- Nr: 회전자 속도 [rpm]

유도전동기는 회전자가 회전자계와 완전히 같은 속도로 회전하면 회전자에 유도전류가 발생하지 않기 때문에, 정상 운전에서는 회전자 속도가 동기속도보다 약간 낮습니다.

---

### 4.3 정격토크

정격 출력과 정격 속도로부터 정격토크를 계산할 수 있습니다.

```text
Pout = ratedPowerKw × 1000
ωrated = 2π × ratedSpeed / 60
Trated = Pout / ωrated
```

---

### 4.4 3상 전류

```text
ia = Im sin(ωt)
ib = Im sin(ωt - 2π/3)
ic = Im sin(ωt - 4π/3)
```

3상 전류는 서로 120도 위상차를 가지며, 고정자 권선에 공급되면 회전하는 합성 자기장을 형성합니다.

---

### 4.5 유도전동기 토크

본 프로그램은 Thevenin 등가회로 기반의 유도전동기 토크식을 사용합니다.

```text
Vphase = VLL / √3
```

```text
Te = [3 × Vth² × (R2 / s)] / [ωs × ((Rth + R2 / s)² + (Xth + X2)²)]
```

실제 구현에서는 슬립이 0에 가까울 때 수치 오류가 발생하지 않도록 최소 슬립값을 적용합니다.

---

### 4.6 부하토크 모델

부하토크는 부하 종류에 따라 속도에 대해 다르게 변화합니다.

```text
정토크 부하:
TL = constant

팬·펌프 부하:
TL ∝ speed²

선박 추진 부하:
TL ∝ speed^2.5
```

---

### 4.7 열 모델

권선온도는 발생 손실과 냉각의 차이에 의해 변합니다.

```text
dT/dt = (Ploss - Qcool) / Cth
```

온도가 상승하면 냉각량도 증가하므로, 일정한 운전 조건에서는 온도가 특정 정상상태 값에 수렴합니다.

## 6. 실행 방법

MotorAnalyzer는 두 가지 방식으로 실행할 수 있습니다.

1. Windows 실행 파일을 다운로드하여 실행
2. GitHub 소스코드를 다운로드하여 개발 서버로 실행

일반 사용자는 Windows 실행 파일을 사용하는 것이 가장 간단합니다.

---

### 6.1 Windows 실행 파일 다운로드

Windows용 실행 파일은 용량이 커서 GitHub 소스코드 저장소에는 직접 포함하지 않았습니다.

아래 Google Drive 폴더에서 실행 파일을 다운로드할 수 있습니다.

```text
https://drive.google.com/drive/folders/1yzt-f9jhrkeS8aim-lhbI25Ehx1rGzDH?usp=sharing
```

다운로드 폴더에는 다음과 같은 파일이 포함될 수 있습니다.

```text
MotorAnalyzer-0.5.16-Portable-x64.exe
MotorAnalyzer-0.5.16-Setup-x64.exe
```

---

### 6.2 Setup 버전으로 설치하기 권장

정확하고 안정적인 실행을 위해서는 `Setup` 버전 설치를 권장합니다.

```text
MotorAnalyzer-0.5.16-Setup-x64.exe
```

Setup 버전은 Windows 프로그램처럼 설치되며, 다음과 같은 장점이 있습니다.

- 시작 메뉴 또는 바탕화면 바로가기 생성 가능
- 설치된 프로그램으로 관리 가능
- 실행 경로와 리소스 구성이 비교적 안정적
- 다른 PC에서도 일반 프로그램처럼 실행 가능

설치 방법:

1. Google Drive 폴더에서 `MotorAnalyzer-0.5.16-Setup-x64.exe` 다운로드
2. 파일 실행
3. 설치 마법사 안내에 따라 설치
4. 설치 완료 후 MotorAnalyzer 실행

Windows 보안 경고가 표시될 경우, 개인 개발 앱이므로 다음 순서로 실행할 수 있습니다.

```text
추가 정보 → 실행
```

---

### 6.3 Portable 버전으로 바로 실행하기

설치 없이 바로 실행하고 싶다면 Portable 버전을 사용할 수 있습니다.

```text
MotorAnalyzer-0.5.16-Portable-x64.exe
```

Portable 버전은 별도 설치 과정 없이 파일을 더블클릭하여 실행할 수 있습니다.

다만 Portable 버전은 Windows 환경이나 보안 설정에 따라 실행 경고가 표시될 수 있으며, 실행 위치에 따라 일부 동작이 다를 수 있습니다. 따라서 오류 없이 안정적으로 사용하려면 Setup 버전 설치를 권장합니다.

실행 방법:

1. Google Drive 폴더에서 `MotorAnalyzer-0.5.16-Portable-x64.exe` 다운로드
2. 원하는 폴더에 파일 저장
3. 파일을 더블클릭하여 실행
4. Windows 보안 경고가 표시되면 `추가 정보 → 실행` 선택

---

### 6.4 소스코드로 실행하기

GitHub 저장소의 소스코드를 직접 실행하려면 Node.js와 npm이 필요합니다.

GitHub 저장소에는 `node_modules` 폴더를 포함하지 않습니다. 따라서 처음 실행할 때는 필요한 패키지를 설치해야 합니다.

#### 6.4.1 사전 준비

Node.js와 npm이 설치되어 있어야 합니다.

설치 여부는 터미널에서 아래 명령어로 확인할 수 있습니다.

```bash
node -v
npm -v
```

버전 숫자가 출력되면 정상적으로 설치된 것입니다.

예시:

```text
v24.5.0
11.12.1
```

만약 `node` 또는 `npm`이 인식되지 않는다면, Node.js LTS 버전을 설치한 뒤 다시 실행해야 합니다.

---

#### 6.4.2 GitHub에서 프로젝트 다운로드

1. GitHub 저장소 페이지에 접속합니다.

```text
https://github.com/Gnho-UOU/motor-analyzer
```

2. 오른쪽 위의 초록색 `Code` 버튼을 클릭합니다.

3. `Download ZIP`을 클릭하여 프로젝트 파일을 다운로드합니다.

4. 다운로드한 ZIP 파일의 압축을 해제합니다.

5. 압축을 해제하면 보통 다음과 같은 폴더가 생성됩니다.

```text
motor-analyzer-main
```

---

#### 6.4.3 VS Code에서 프로젝트 열기

1. Visual Studio Code를 실행합니다.

2. 상단 메뉴에서 다음을 선택합니다.

```text
File → Open Folder
```

3. 압축을 해제한 프로젝트 폴더를 선택합니다.

```text
motor-analyzer-main
```

4. 폴더가 열리면 VS Code 왼쪽 파일 목록에 다음과 같은 파일들이 보여야 합니다.

```text
src
public
package.json
package-lock.json
README.md
vite.config.js
```

---

#### 6.4.4 터미널 열기

VS Code 상단 메뉴에서 다음을 선택합니다.

```text
Terminal → New Terminal
```

또는 단축키를 사용할 수 있습니다.

```text
Ctrl + `
```

터미널이 열리면 현재 위치가 프로젝트 폴더인지 확인합니다.

예시:

```text
PS C:\Users\사용자이름\Downloads\motor-analyzer-main>
```

만약 프로젝트 폴더가 아니라면 `cd` 명령어로 프로젝트 폴더로 이동합니다.

예시:

```bash
cd C:\Users\사용자이름\Downloads\motor-analyzer-main
```

---

#### 6.4.5 필요한 패키지 설치

처음 실행할 때는 아래 명령어를 입력하여 필요한 라이브러리를 설치합니다.

```bash
npm install
```

이 명령어를 실행하면 `package.json`과 `package-lock.json`에 기록된 정보를 바탕으로 필요한 패키지들이 자동으로 설치되고, `node_modules` 폴더가 생성됩니다.

---

#### 6.4.6 개발 서버 실행

패키지 설치가 끝나면 아래 명령어를 입력합니다.

```bash
npm run dev
```

정상적으로 실행되면 터미널에 다음과 비슷한 주소가 표시됩니다.

```text
Local: http://localhost:5173/
```

브라우저에서 해당 주소로 접속하면 MotorAnalyzer 시뮬레이터를 실행할 수 있습니다.

```text
http://localhost:5173/
```

---

#### 6.4.7 포트 번호가 다른 경우

만약 `5173` 포트가 이미 사용 중이면 Vite가 자동으로 다른 포트를 사용할 수 있습니다.

예시:

```text
Port 5173 is in use, trying another one...
Local: http://localhost:5174/
```

이 경우에는 터미널에 표시된 주소로 접속하면 됩니다.

#### 6.4.8 실행 종료 방법

시뮬레이터 실행을 종료하려면 VS Code 터미널에서 다음 키를 누릅니다.

```text
Ctrl + C
```

종료 여부를 묻는 메시지가 나오면 `Y`를 입력하고 Enter를 누릅니다.

---

#### 6.4.9 이후 다시 실행하는 방법

한 번 `npm install`을 실행한 뒤에는 매번 다시 설치할 필요가 없습니다.

다음부터는 프로젝트 폴더에서 아래 명령어만 실행하면 됩니다.

```bash
npm run dev
```

단, `node_modules` 폴더를 삭제했거나 다른 컴퓨터에서 처음 실행하는 경우에는 다시 아래 명령어를 먼저 실행해야 합니다.

```bash
npm install
```
