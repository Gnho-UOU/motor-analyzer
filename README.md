# MotorAnalyzer  
## AI 코딩을 활용한 3상 유도전동기 회전자계 및 기동 특성 시뮬레이터

---

## 1. 프로젝트 소개

본 프로젝트는 전기전자공학 전공 지식을 소프트웨어적으로 구현하기 위해 제작한 **3상 유도전동기 시뮬레이션 웹 애플리케이션**이다.

React와 Vite를 기반으로 개발하였으며, AI 코딩 도구를 활용하여 3상 유도전동기의 회전자계 형성, 슬립, 동기속도, 토크-속도 특성, 기동 과정, 운전 상태 경고 등을 시각적으로 확인할 수 있도록 구성하였다.

사용자는 전원 주파수, 극수, 전압, 고정자 저항, 회전자 저항, 리액턴스, 부하토크 등의 값을 조절하면서 전동기의 동작 변화를 실시간으로 확인할 수 있다.

---

## 2. 개발 목적

본 프로그램의 목적은 3상 유도전동기의 핵심 동작 원리를 단순한 공식 암기가 아니라, 시뮬레이션과 시각화를 통해 직관적으로 이해하는 것이다.

특히 다음 내용을 교육적으로 확인할 수 있도록 제작하였다.

- 3상 전류에 의해 회전자계가 형성되는 과정
- 동기속도와 회전자속도의 차이
- 슬립의 의미
- 부하토크 변화에 따른 운전점 변화
- 기동 시 회전자 속도 상승 과정
- 토크-속도 곡선의 의미
- 정지, 기동, 정상 운전, 비상정지 상태의 차이

---

## 3. 주요 기능

### 3.1 전동기 제어반

산업 현장에서 사용하는 전동기 제어반 느낌을 반영하여 START, RESET, EMERGENCY STOP 버튼과 상태 표시등을 구현하였다.

- START 버튼: 전동기 기동 시뮬레이션 시작
- RESET 버튼: 시뮬레이션 초기화
- EMERGENCY STOP 버튼: 비상정지 상태 구현
- RUN, STARTING, STOP 상태 표시등 제공

---

### 3.2 회전자계 시각화

3상 전류가 고정자 권선에 공급될 때 생성되는 회전자계를 SVG 애니메이션으로 표현하였다.

- START 상태에서 회전자계 ON
- STOP, RESET, EMERGENCY STOP 상태에서는 회전자계 OFF
- 회전자계는 동기속도로 회전
- 회전자는 슬립에 의해 회전자계보다 느리게 회전

---

### 3.3 3D 전동기 모델

전동기를 단순한 2D 단면이 아니라, 3D 느낌의 시각화 모델로 표현하였다.

시각화 모델에서는 다음 요소를 확인할 수 있다.

- 고정자
- 회전자
- 회전축
- 회전자계 방향
- 회전자 회전 상태

---

### 3.4 기동 특성 시뮬레이션

전동기가 정지 상태에서 정상 운전 상태로 도달하는 과정을 단순 동역학 모델로 시뮬레이션하였다.

사용한 기본 모델은 다음과 같다.

```text
J * dω/dt = Te - TL - Bω
```

이를 통해 시간에 따른 다음 변화를 확인할 수 있다.

- 회전자 속도
- 슬립
- 전자기 토크
- 기동 상태

---

### 3.5 토크-속도 특성 곡선

유도전동기의 토크-속도 특성 곡선을 그래프로 표시하였다.

또한 부하토크와 전동기 토크가 만나는 운전점을 자동으로 추적하여, 부하 변화에 따라 회전자 속도와 슬립이 어떻게 변하는지 확인할 수 있다.

---

### 3.6 운전조건 프리셋

다양한 운전 조건을 빠르게 확인할 수 있도록 프리셋 기능을 구현하였다.

예시:

- 무부하 운전
- 정격부하 운전
- 과부하 운전
- 저전압 운전
- 고슬립 운전

프리셋은 입력값만 변경하며, 전동기를 자동으로 기동하지 않는다.  
전동기 기동은 반드시 제어반의 START 버튼을 통해 수행된다.

---

### 3.7 운전상태 경고

시뮬레이션 결과를 바탕으로 교육용 경고 메시지를 표시한다.

예시:

- 슬립 과다
- 기동토크 부족
- 저전압 운전
- 토크 부족
- 속도 저하 가능성

해당 경고는 실제 산업용 보호계전기 수준의 판단이 아니라, 학습을 돕기 위한 교육용 지표이다.

## 4. 사용한 주요 전기전자공학 이론

### 4.1 동기속도

```text
Ns = 120f / P
```

- Ns: 동기속도 [rpm]
- f: 전원 주파수 [Hz]
- P: 극수

---

### 4.2 슬립

```text
s = (Ns - Nr) / Ns
```

- s: 슬립
- Ns: 동기속도 [rpm]
- Nr: 회전자속도 [rpm]

유도전동기는 회전자가 회전자계와 완전히 같은 속도로 회전하면 유도기전력이 발생하지 않기 때문에, 정상 운전 시 회전자는 동기속도보다 약간 느리게 회전한다.

---

### 4.3 회전자 속도

```text
Nr = Ns(1 - s)
```

슬립이 증가하면 회전자 속도는 감소하고, 부하가 증가할수록 일반적으로 슬립이 증가한다.

---

### 4.4 3상 전류

```text
ia = Im sin(ωt)
ib = Im sin(ωt - 2π/3)
ic = Im sin(ωt - 4π/3)
```

3상 전류는 서로 120도 위상차를 가지며, 이 전류들이 고정자 권선에 흐르면 합성 자기장이 회전하는 회전자계가 형성된다.

---

### 4.5 유도전동기 전자기 토크

본 시뮬레이터는 Thevenin 등가회로를 이용하여 유도전동기의 전자기 토크를 계산하였다.

```text
Vphase = VLL / √3
```

```text
Te = [3 * Vth² * (R2 / s)] / [ωs * ((Rth + R2 / s)² + (Xth + X2)²)]
```

여기서 슬립이 0에 가까워질 때 계산 오류가 발생하지 않도록 최소 슬립값을 적용하였다.

---

### 4.6 리액턴스와 주파수

리액턴스는 다음 관계에 의해 주파수에 영향을 받는다.

```text
X = 2πfL
```

본 시뮬레이터에서는 사용자가 입력한 리액턴스 값을 기준으로 계산하며, 주파수 변화에 따른 리액턴스 보정 기능을 통해 주파수 변화가 전동기 특성에 미치는 영향도 확인할 수 있도록 구성하였다.

## 5. AI 코딩 활용 과정

본 프로젝트는 AI 코딩 도구를 활용하여 다음 과정으로 개발하였다.

1. ChatGPT를 활용하여 프로그램 주제 선정 및 전기기기 이론 정리
2. Codex를 활용하여 React + Vite 기반 웹앱 구조 생성
3. 3상 유도전동기 공식과 토크-속도 곡선 계산 로직 구현
4. SVG를 활용한 회전자계 및 전동기 시각화 구현
5. 제어반 START, RESET, EMERGENCY STOP UI 구현
6. 기동 특성 그래프와 3상 전류 파형 그래프 구현
7. STOP 상태에서 회전자계 OFF, 슬립 N/A 표시 등 이론적 오류 수정
8. 프리셋 동작, 경고판, 3D 모델, 레이아웃을 반복적으로 개선

AI를 단순히 코드 생성에만 사용한 것이 아니라, 전기전자 이론이 실제 프로그램 동작과 모순되지 않도록 수정하는 과정에서도 활용하였다.

## 6. 실행 방법

본 프로젝트는 React + Vite 기반 웹 애플리케이션이다.

GitHub 저장소에는 용량이 큰 `node_modules` 폴더를 포함하지 않았다.  
`node_modules`는 실행에 필요한 외부 라이브러리들이 설치되는 폴더이며, `package.json`과 `package-lock.json`을 이용하여 동일하게 다시 설치할 수 있다.

처음 실행할 때는 프로젝트 폴더에서 아래 명령어를 실행한다.

```bash
npm install
```

그다음 개발 서버를 실행한다.

```bash
npm run dev
```

실행 후 터미널에 표시되는 localhost 주소로 접속하면 된다.

예시:

```text
http://localhost:5173/
```

만약 5173 포트가 이미 사용 중이면 Vite가 자동으로 다른 포트를 안내한다.

예시:

```text
http://localhost:5174/
```

이 경우 터미널에 표시된 주소로 접속하면 된다.
