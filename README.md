# MotorAnalyzer v0.6.2

## AI 코딩을 활용한 3상 유도전동기 운전점·기동·열 특성 시뮬레이터

MotorAnalyzer는 3상 유도전동기의 정격 운전, 기동 특성, 부하 모델, 토크-속도 곡선, 권선 온도 상승, 운전 상태 경고를 시각적으로 확인할 수 있도록 제작한 교육용 전동기 해석 프로그램입니다.

React, Vite, Electron을 기반으로 개발하였으며, OpenAI ChatGPT와 Codex를 활용하여 기능 설계, 코드 구현, 오류 수정, 시뮬레이션 구조 개선을 반복하며 제작하였습니다.

## 1. 프로젝트 개요

본 프로젝트는 전기전자공학에서 다루는 3상 유도전동기의 핵심 개념을 단순 공식 계산이 아니라, 실제 프로그램 형태의 시뮬레이션으로 확인하기 위해 제작되었습니다.

사용자는 Wizard를 통해 전동기 종류, 제조사, 정격 사양, 부하 모델, 시험 목적을 설정할 수 있으며, 이후 Dashboard에서 전동기의 운전점, 기동 과정, 토크-속도 특성, 전류 파형, 열 상태, 운전 경고를 확인할 수 있습니다.

주요 해석 대상은 다음과 같습니다.

- 3상 유도전동기의 회전자계 형성
- 동기속도와 회전자속도
- 슬립과 전자기 토크
- 정격부하 운전점
- 기동 특성
- 부하 모델별 기동 차이
- 저전압, 과부하, 고슬립 운전
- 권선 온도 상승 및 냉각 효과
- 운전 상태 경고
- Three.js 기반 고급 3D 전동기 모델
- WebGL/GPU 가속 기반 3D 시각화
- PDF 리포트 생성
- Windows 실행 파일 패키징

> 본 프로그램은 교육용 시뮬레이터입니다. 실제 산업 현장의 전동기 선정, 보호계전기 설정, 열해석, 기동 검토, 설비 설계에는 반드시 제조사 데이터시트, 실제 시험 데이터, 현장 조건, 관련 표준을 함께 검토해야 합니다.

## 2. 개발 목적

MotorAnalyzer의 목적은 3상 유도전동기의 이론을 시각적으로 이해하고, 전동기 운전 조건이 바뀔 때 속도, 토크, 슬립, 부하, 온도, 경고 상태가 어떻게 변하는지 확인하는 것입니다.

특히 다음 내용을 교육적으로 확인할 수 있도록 구성했습니다.

- 정격전압, 정격주파수, 극수에 따른 동기속도 계산
- 명판값을 이용한 정격토크 및 정격슬립 계산
- Thevenin 등가회로 기반 유도전동기 토크 계산
- 부하토크와 전동기 토크가 만나는 운전점 분석
- 정격부하 운전과 정지 상태 기동의 차이
- 정토크 부하, 팬·펌프 부하, 선박 추진 부하의 차이
- 기동 중 속도, 슬립, 토크 변화
- 손실 및 권선온도 상승의 교육용 추정
- 운전 조건에 따른 경고 및 판정

## 3. 주요 기능

### 3.1 Setup Wizard

프로그램 실행 후 사용자는 Wizard를 통해 시험 조건을 단계적으로 입력할 수 있습니다.

현재 Wizard는 다음과 같은 흐름으로 구성되어 있습니다.

1. 사용자 정보 입력
2. 전동기 유형 선택
3. 제조사 선택
4. 전동기 정격 사양 입력
5. 시험 목적 및 부하 조건 설정
6. 입력 정보 검토
7. 리포트 생성 준비

Wizard 4단계에서는 전동기 명판값을 직접 입력하거나, 예시 전동기 값을 적용할 수 있습니다.

주요 입력값은 다음과 같습니다.

- 정격 출력 [kW]
- 정격 전압 [V]
- 정격 주파수 [Hz]
- 극수
- 정격 속도 [rpm]
- 정격 전류 [A]
- 역률
- 효율 [%]
- 관성 J
- 부하 모델
- 등가회로 파라미터
- 공급 전압 및 공급 주파수

### 3.3 Active Motor Profile 기반 자동 설정

현재 버전에서는 Wizard 4단계에 입력된 전동기 정격 사양을 기준으로 시뮬레이션 초기값이 자동 설정됩니다.

전동기 명판값이 바뀌면 다음 항목도 함께 자동 계산됩니다.

- 정격토크
- 정격슬립
- 동기속도
- 정격부하 토크
- 무부하/정격부하/과부하/저전압/고슬립 프리셋
- 부하토크 범위
- 전압 및 주파수 범위
- 열모델 기본값
- 등가회로 추정값
- 토크 보정 계수
- Dashboard 초기 표시값

이를 통해 15 kW, 75 kW, 1750 kW급 전동기를 선택하더라도 각 전동기 크기에 맞는 운전 조건이 자동으로 적용됩니다.

### 3.4 운전조건 프리셋

현재 지원하는 프리셋은 다음과 같습니다.

- 무부하 운전
- 정격부하 운전
- 과부하 운전
- 저전압 운전
- 고슬립 운전
- 사용자 설정

프리셋은 고정된 수치가 아니라, 현재 선택된 전동기 정격값을 기준으로 자동 생성됩니다.

```text
무부하     ≈ 정격토크의 5%
정격부하   = 정격토크의 100%
과부하     ≈ 정격토크의 150%
저전압     = 정격전압의 80%
고슬립     ≈ 정격토크의 150~180%
```

### 3.5 부하 모델

MotorAnalyzer는 부하의 종류에 따라 속도별 부하토크가 다르게 변하도록 구성되어 있습니다.

#### 정토크 부하

속도와 관계없이 부하토크가 거의 일정한 부하입니다.

```text
TL(speed) = TL_rated
```

컨베이어, 압축기, 일부 기계 부하를 단순화할 때 사용할 수 있습니다.

#### 팬·펌프 부하

속도가 증가할수록 부하토크가 제곱에 비례하여 증가하는 부하입니다.

```text
TL(speed) = TL_rated × (speed / ratedSpeed)^2
```

팬, 펌프, 블로어 부하를 설명할 때 사용할 수 있습니다.

#### 선박 추진 부하

프로펠러 부하처럼 속도 증가에 따라 부하토크가 더 강하게 증가하는 형태입니다.

```text
TL(speed) = TL_rated × (speed / ratedSpeed)^2.5
```

#### 사용자 정의 부하

사용자가 입력한 조건을 기준으로 부하토크를 직접 설정할 수 있습니다.

### 3.6 정격부하 운전과 기동 시뮬레이션 분리

현재 버전에서는 정격부하 운전과 기동 시뮬레이션을 구분합니다.

정격부하 운전은 정상 운전점에서의 해석입니다.

```text
Nr ≈ ratedSpeed
slip ≈ ratedSlip
Te ≈ TL
```

반면 START 버튼을 누르면 전동기는 0 rpm에서 기동을 시작합니다.

이때 부하모델에 따라 초기 부하토크가 다르게 적용됩니다.

```text
정토크 부하      → 0 rpm에서도 큰 부하토크
팬·펌프 부하    → 0 rpm에서 부하토크 거의 0
선박 추진 부하  → 0 rpm에서 부하토크 거의 0
```

따라서 정격부하 운전이 가능하더라도, 정토크 부하를 정지 상태에서 바로 기동하는 경우에는 기동 실패가 발생할 수 있습니다.

### 3.7 전동기 제어반

Dashboard에는 산업용 전동기 제어반 느낌의 조작부가 포함되어 있습니다.

- START
- RESET
- EMERGENCY STOP
- RUN 표시등
- STARTING 표시등
- STOP 표시등

START를 누르면 기동 시뮬레이션이 시작되며, STOP 또는 EMERGENCY STOP 시 회전자계가 OFF되고 회전자는 관성에 의해 감속됩니다.

### 3.8 회전자계 및 전동기 단면 시각화

전동기 단면 시각화에서는 고정자, 회전자, 3상 전류, 회전자계 방향, 회전자 속도, 슬립 상태를 확인할 수 있습니다.

주요 표현 요소는 다음과 같습니다.

- 고정자
- 회전자
- A상, B상, C상 전류
- 회전자계 방향
- 회전자 속도
- 슬립 표시
- 전원 OFF 상태의 회전자계 비활성화

v0.6.2에서는 단면 시각화에서도 실제 동기속도 `Ns`와 회전자속도 `Nr` 값을 같은 시각 배율로 반영하여, 회전자계와 회전자가 서로 다른 속도로 움직이는 모습을 더 자연스럽게 표현하도록 개선했습니다. 이를 통해 슬립이 단순 숫자 표시가 아니라, 회전자계와 회전자 사이의 상대적인 속도 차이로도 이해될 수 있도록 구성했습니다.

### 3.9 Three.js 기반 고급 3D 전동기 모델

v0.6.2에서는 기존의 단순한 3D 스타일 전동기 표현을 Three.js 기반 WebGL 3D 시각화로 교체했습니다. 이전 버전의 모델은 3D 느낌을 주는 교육용 시각화에 가까웠지만, 현재 버전에서는 실제 산업용 TEFC 유도전동기의 외형을 참고하여 더 알아보기 쉬운 3D 모델로 재구성했습니다.

3D 모델에는 다음 요소를 포함했습니다.

- 가로 원통형 전동기 하우징
- 고정자 / Stator
- 회전자 / Rotor
- 회전축 / Shaft
- 후면 냉각팬 / Cooling fan
- 후면 팬 가드 및 그릴
- 길이 방향 냉각핀
- 전후 엔드실드
- 상부 단자함
- 케이블 글랜드
- 베이스 풋 및 레일
- 전면 축 및 커플링 회전 표시
- 동기 회전자계 링
- 회전자 속도 링
- 전력 흐름 입자 효과
- 권선온도 기반 열 glow
- 경고 심각도 기반 위험 glow
- 비상정지 상태 시 빨간 경고 효과
- 부품 설명 라벨

3D 모델은 기존 시뮬레이션 계산값을 받아 시각적으로 표현하는 구조입니다. 토크, 슬립, 속도, 열 상태, 경고 판정 등은 기존 계산 로직에서 수행하고, Three.js 모델은 해당 결과를 기반으로 회전, 색상, glow, 전력 흐름 효과를 표시합니다.

팬, 회전자, 회전자 속도 링은 현재 표시되는 회전자 속도 `Nr` 값을 기준으로 회전합니다.

```text
omega = rpm × 2π / 60
```

동기 회전자계 링은 동기속도 `Ns` 기준으로 회전하며, 전원이 꺼졌거나 회전자계가 OFF인 상태에서는 흐려지거나 정지하도록 구성했습니다. 이를 통해 START 전 대기 상태에서는 3D 회전자와 팬이 불필요하게 회전하지 않고, STARTING, RUN, COASTING, EMERGENCY STOP 상태에서만 실제 상태에 맞게 움직이도록 수정했습니다.

또한 전원 → 단자함 → 고정자 → 회전자 → 축 방향으로 흐르는 전력 흐름 효과를 추가하여, 전동기에 에너지가 전달되는 과정을 시각적으로 확인할 수 있도록 했습니다. 단, 이 효과는 실제 전력해석을 수행하는 기능이 아니라, 기존 계산 결과와 운전 상태를 이해하기 쉽게 보여주기 위한 시각적 표현입니다.

그래픽 성능 측면에서는 Three.js의 WebGL 렌더링을 사용하여 3D 모델과 애니메이션이 GPU 가속을 활용할 수 있도록 구성했습니다. Electron 설정에서도 하드웨어 가속을 비활성화하지 않도록 수정하여, 기존 CPU 중심 시각화에서 발생하던 지연과 렉을 줄이고 전동기 3D 모델이 더 부드럽게 동작하도록 개선했습니다.

> 전동기 토크 계산, 슬립 계산, 부하모델, 열 계산, 경고 판정 등 공학적 계산은 기존 JavaScript 계산 로직을 사용합니다. GPU 가속은 주로 Three.js/WebGL 기반 3D 그래픽 렌더링과 애니메이션 표현에 적용됩니다.

### 3.10 토크-속도 특성 곡선

토크-속도 특성 곡선에서는 다음 정보를 확인할 수 있습니다.

- 전동기 토크 곡선
- 부하토크 곡선
- 기동토크 지점
- 최대토크 지점
- 운전점
- 정격 조건 기준 곡선
- Thevenin 등가회로 파라미터

운전점은 전동기 토크와 부하토크가 만나는 지점으로, 해당 지점에서 회전자 속도와 슬립이 결정됩니다.

---

### 3.11 기동 특성 그래프

기동 특성 그래프에서는 START 이후 시간에 따른 다음 변화를 확인할 수 있습니다.

- 회전자 속도 Nr(t)
- 부하토크 TL(t)
- 전자기 토크 Te(t)
- 슬립 s(t)

기동 시뮬레이션은 다음의 단순 동역학 모델을 기반으로 합니다.

```text
J × dω/dt = Te - TL - Bω
```

---

### 3.12 3상 전류 파형

A상, B상, C상 전류가 서로 120도 위상차를 갖는 것을 그래프로 확인할 수 있습니다.

```text
ia = Im sin(ωt)
ib = Im sin(ωt - 2π/3)
ic = Im sin(ωt - 4π/3)
```

이는 3상 전류가 회전자계를 형성하는 원리를 시각적으로 보여주기 위한 교육용 모델입니다.

---

### 3.13 등가회로 파라미터

유도전동기의 Thevenin 등가회로 해석을 위해 다음 파라미터를 사용합니다.

- R1: 고정자 저항
- R2': 회전자 저항
- X1: 고정자 누설 리액턴스
- X2': 회전자 누설 리액턴스
- Xm: 자화 리액턴스
- Rc: 철손 저항

정격값 기반 교육용 추정 모드에서는 정격 슬립 지점에서 전자기 토크가 정격토크와 일치하도록 토크 곡선을 보정합니다.

> 실제 제품의 등가회로 파라미터는 무부하 시험, 구속 시험, 제조사 데이터시트 등을 통해 얻어야 합니다.

---

### 3.14 권선온도 및 열 모델

MotorAnalyzer는 손실과 냉각을 고려한 단순 열 모델을 포함합니다.

기본 열 모델은 다음과 같은 열평형 개념을 사용합니다.

```text
dT/dt = (Ploss - Qcool) / Cth
```

여기서 냉각은 다음과 같이 단순화됩니다.

```text
Qcool = (T - Tambient) / Rth_effective
```

또한 실제 전동기에는 냉각팬과 프레임 방열이 존재하므로, 회전자 속도에 따라 냉각 효과가 달라지도록 구성했습니다.

```text
speedRatio = rotorSpeed / ratedSpeed
fanCoolingFactor = naturalCooling + forcedCooling × speedRatio^fanExponent
```

v0.6.2에서는 기존 열모델에서 권선온도가 허용 권선온도를 비현실적으로 크게 초과하면서 계속 상승하는 문제를 개선했습니다. 명판 정격출력과 효율을 이용해 정격 손실을 계산하고, 등가회로 손실 추정값이 비정상적으로 크게 튀는 경우에는 열모델에 명판 효율 기반의 연속 운전 손실 한계를 적용하도록 수정했습니다.

또한 정격 연속 운전 시 허용 권선온도에 바로 붙지 않도록 유효 열저항을 보정하고, STARTING 상태와 RUN 상태의 열부하 적용 방식을 구분했습니다. STARTING 상태에서는 과도 손실을 더 크게 허용하고, RUN 상태에서는 팬 냉각이 반영된 연속 열부하 기준으로 계산하도록 구성했습니다.

이를 통해 권선온도가 무한히 계속 상승하는 비현실적인 표현을 줄이고, 손실과 냉각의 균형에 따라 정상상태 온도에 접근하는 교육용 열 거동에 가깝게 수정했습니다.

## 4. 사용한 주요 이론

### 4.1 동기속도

```text
Ns = 120f / P
```

- Ns: 동기속도 [rpm]
- f: 전원 주파수 [Hz]
- P: 극수

---

### 4.2 슬립

```text
s = (Ns - Nr) / Ns
```

- s: 슬립
- Ns: 동기속도 [rpm]
- Nr: 회전자 속도 [rpm]

유도전동기는 회전자가 회전자계와 완전히 같은 속도로 회전하면 회전자에 유도전류가 발생하지 않기 때문에, 정상 운전에서는 회전자 속도가 동기속도보다 약간 낮습니다.

---

### 4.3 정격토크

정격 출력과 정격 속도로부터 정격토크를 계산할 수 있습니다.

```text
Pout = ratedPowerKw × 1000
ωrated = 2π × ratedSpeed / 60
Trated = Pout / ωrated
```

---

### 4.4 3상 전류

```text
ia = Im sin(ωt)
ib = Im sin(ωt - 2π/3)
ic = Im sin(ωt - 4π/3)
```

3상 전류는 서로 120도 위상차를 가지며, 고정자 권선에 공급되면 회전하는 합성 자기장을 형성합니다.

---

### 4.5 유도전동기 토크

본 프로그램은 Thevenin 등가회로 기반의 유도전동기 토크식을 사용합니다.

```text
Vphase = VLL / √3
```

```text
Te = [3 × Vth² × (R2 / s)] / [ωs × ((Rth + R2 / s)² + (Xth + X2)²)]
```

실제 구현에서는 슬립이 0에 가까울 때 수치 오류가 발생하지 않도록 최소 슬립값을 적용합니다.

---

### 4.6 부하토크 모델

부하토크는 부하 종류에 따라 속도에 대해 다르게 변화합니다.

```text
정토크 부하:
TL = constant

팬·펌프 부하:
TL ∝ speed²

선박 추진 부하:
TL ∝ speed^2.5
```

---

### 4.7 열 모델

권선온도는 발생 손실과 냉각의 차이에 의해 변합니다.

```text
dT/dt = (Ploss - Qcool) / Cth
```

온도가 상승하면 냉각량도 증가하므로, 일정한 운전 조건에서는 온도가 특정 정상상태 값에 수렴합니다.

### 6.4 소스코드로 실행하기

```bash
node -v
npm -v
```

버전 숫자가 출력되면 정상적으로 설치된 것입니다.

예시:

```text
v24.5.0
11.12.1
```

만약 `node` 또는 `npm`이 인식되지 않는다면, Node.js LTS 버전을 설치한 뒤 다시 실행해야 합니다.

이 명령어를 실행하면 `package.json`과 `package-lock.json`에 기록된 정보를 바탕으로 필요한 패키지들이 자동으로 설치되고, `node_modules` 폴더가 생성됩니다.

#### 6.4.6 개발 서버 실행

패키지 설치가 끝나면 아래 명령어를 입력합니다.

```bash

```

정상적으로 실행되면 터미널에 다음과 비슷한 주소가 표시됩니다.

```text
Local: http://localhost:5173/
```

```text
http://localhost:5173/
```

#### 6.4.7 포트 번호가 다른 경우

예시:

```text
Port 5173 is in use, trying another one...
Local: http://localhost:5174/
```

이 경우에는 터미널에 표시된 주소로 접속하면 됩니다.

## 9. 한계 및 주의사항

MotorAnalyzer는 교육용 시뮬레이터이며, 실제 산업용 전동기 해석 프로그램을 완전히 대체하지 않습니다.

다음 항목은 실제 현장 적용 시 추가 검토가 필요합니다.

- 실제 제조사 등가회로 파라미터
- 무부하 시험 및 구속 시험 데이터
- 실제 기동전류
- 실제 기동토크
- 최대토크 및 breakdown torque
- 전원 임피던스와 전압강하
- 보호계전기 설정
- 정확한 열해석
- 냉각 구조
- 부하 관성
- 실제 부하 토크-속도 특성
- 인버터 및 소프트스타터 제어 알고리즘
- 실제 전동기 3D 형상 치수 및 제조사별 상세 구조
- WebGL/GPU 가속 지원 여부에 따른 그래픽 성능 차이

따라서 본 프로그램의 결과는 학습, 발표, 보고서, 개념 검증 용도로 사용하는 것이 적절합니다. 또한 Three.js 3D 모델은 실제 산업용 전동기의 외형을 참고한 교육용 시각화이며, 제조사 도면 수준의 정확한 기계 설계 모델은 아닙니다.
