# MotorAnalyzer  
## AI 코딩을 활용한 3상 유도전동기 회전자계 및 기동 특성 시뮬레이터

> ⚠️ **실행 전 필독**
>
> 이 프로젝트는 `node_modules` 폴더를 포함하지 않으므로, 다운로드 후 바로 실행되지 않을 수 있습니다.  
> 반드시 아래의 **[6. 실행 방법](#6-실행-방법)** 을 먼저 읽고, `npm install` 후 `npm run dev` 순서로 실행해 주세요.

---

## 1. 프로젝트 소개

본 프로젝트는 전기전자공학 전공 지식을 소프트웨어적으로 구현하기 위해 제작한 **3상 유도전동기 시뮬레이션 웹 애플리케이션**이다.

React와 Vite를 기반으로 개발하였으며, AI 코딩 도구를 활용하여 3상 유도전동기의 회전자계 형성, 슬립, 동기속도, 토크-속도 특성, 기동 과정, 운전 상태 경고 등을 시각적으로 확인할 수 있도록 구성하였다.

사용자는 전원 주파수, 극수, 전압, 고정자 저항, 회전자 저항, 리액턴스, 부하토크 등의 값을 조절하면서 전동기의 동작 변화를 실시간으로 확인할 수 있다.

---

## 2. 개발 목적

본 프로그램의 목적은 3상 유도전동기의 핵심 동작 원리를 단순한 공식 암기가 아니라, 시뮬레이션과 시각화를 통해 직관적으로 이해하는 것이다.

특히 다음 내용을 교육적으로 확인할 수 있도록 제작하였다.

- 3상 전류에 의해 회전자계가 형성되는 과정
- 동기속도와 회전자속도의 차이
- 슬립의 의미
- 부하토크 변화에 따른 운전점 변화
- 기동 시 회전자 속도 상승 과정
- 토크-속도 곡선의 의미
- 정지, 기동, 정상 운전, 비상정지 상태의 차이

---

## 3. 주요 기능

### 3.1 전동기 제어반

산업 현장에서 사용하는 전동기 제어반 느낌을 반영하여 START, RESET, EMERGENCY STOP 버튼과 상태 표시등을 구현하였다.

- START 버튼: 전동기 기동 시뮬레이션 시작
- RESET 버튼: 시뮬레이션 초기화
- EMERGENCY STOP 버튼: 비상정지 상태 구현
- RUN, STARTING, STOP 상태 표시등 제공

---

### 3.2 회전자계 시각화

3상 전류가 고정자 권선에 공급될 때 생성되는 회전자계를 SVG 애니메이션으로 표현하였다.

- START 상태에서 회전자계 ON
- STOP, RESET, EMERGENCY STOP 상태에서는 회전자계 OFF
- 회전자계는 동기속도로 회전
- 회전자는 슬립에 의해 회전자계보다 느리게 회전

---

### 3.3 3D 전동기 모델

전동기를 단순한 2D 단면이 아니라, 3D 느낌의 시각화 모델로 표현하였다.

시각화 모델에서는 다음 요소를 확인할 수 있다.

- 고정자
- 회전자
- 회전축
- 회전자계 방향
- 회전자 회전 상태

---

### 3.4 기동 특성 시뮬레이션

전동기가 정지 상태에서 정상 운전 상태로 도달하는 과정을 단순 동역학 모델로 시뮬레이션하였다.

사용한 기본 모델은 다음과 같다.

```text
J * dω/dt = Te - TL - Bω
```

이를 통해 시간에 따른 다음 변화를 확인할 수 있다.

- 회전자 속도
- 슬립
- 전자기 토크
- 기동 상태

---

### 3.5 토크-속도 특성 곡선

유도전동기의 토크-속도 특성 곡선을 그래프로 표시하였다.

또한 부하토크와 전동기 토크가 만나는 운전점을 자동으로 추적하여, 부하 변화에 따라 회전자 속도와 슬립이 어떻게 변하는지 확인할 수 있다.

---

### 3.6 운전조건 프리셋

다양한 운전 조건을 빠르게 확인할 수 있도록 프리셋 기능을 구현하였다.

예시:

- 무부하 운전
- 정격부하 운전
- 과부하 운전
- 저전압 운전
- 고슬립 운전

프리셋은 입력값만 변경하며, 전동기를 자동으로 기동하지 않는다.  
전동기 기동은 반드시 제어반의 START 버튼을 통해 수행된다.

---

### 3.7 운전상태 경고

시뮬레이션 결과를 바탕으로 교육용 경고 메시지를 표시한다.

예시:

- 슬립 과다
- 기동토크 부족
- 저전압 운전
- 토크 부족
- 속도 저하 가능성

해당 경고는 실제 산업용 보호계전기 수준의 판단이 아니라, 학습을 돕기 위한 교육용 지표이다.

## 4. 사용한 주요 전기전자공학 이론

### 4.1 동기속도

```text
Ns = 120f / P
```

- Ns: 동기속도 [rpm]
- f: 전원 주파수 [Hz]
- P: 극수

---

### 4.2 슬립

```text
s = (Ns - Nr) / Ns
```

- s: 슬립
- Ns: 동기속도 [rpm]
- Nr: 회전자속도 [rpm]

유도전동기는 회전자가 회전자계와 완전히 같은 속도로 회전하면 유도기전력이 발생하지 않기 때문에, 정상 운전 시 회전자는 동기속도보다 약간 느리게 회전한다.

---

### 4.3 회전자 속도

```text
Nr = Ns(1 - s)
```

슬립이 증가하면 회전자 속도는 감소하고, 부하가 증가할수록 일반적으로 슬립이 증가한다.

---

### 4.4 3상 전류

```text
ia = Im sin(ωt)
ib = Im sin(ωt - 2π/3)
ic = Im sin(ωt - 4π/3)
```

3상 전류는 서로 120도 위상차를 가지며, 이 전류들이 고정자 권선에 흐르면 합성 자기장이 회전하는 회전자계가 형성된다.

---

### 4.5 유도전동기 전자기 토크

본 시뮬레이터는 Thevenin 등가회로를 이용하여 유도전동기의 전자기 토크를 계산하였다.

```text
Vphase = VLL / √3
```

```text
Te = [3 * Vth² * (R2 / s)] / [ωs * ((Rth + R2 / s)² + (Xth + X2)²)]
```

여기서 슬립이 0에 가까워질 때 계산 오류가 발생하지 않도록 최소 슬립값을 적용하였다.

---

### 4.6 리액턴스와 주파수

리액턴스는 다음 관계에 의해 주파수에 영향을 받는다.

```text
X = 2πfL
```

본 시뮬레이터에서는 사용자가 입력한 리액턴스 값을 기준으로 계산하며, 주파수 변화에 따른 리액턴스 보정 기능을 통해 주파수 변화가 전동기 특성에 미치는 영향도 확인할 수 있도록 구성하였다.

## 5. AI 코딩 활용 과정

본 프로젝트는 AI 코딩 도구를 단순히 코드 생성용으로만 사용한 것이 아니라, 사용자가 직접 프로그램의 주제와 기능 방향을 정하고, AI의 도움을 받아 구현과 수정 과정을 반복하는 방식으로 개발하였다.

1. 전기전자 분야에서 교육적으로 활용할 수 있는 프로그램 주제를 검토하였다.

2. 여러 후보 중에서 3상 유도전동기의 회전자계, 슬립, 토크-속도 특성, 기동 과정을 시각적으로 확인할 수 있는 시뮬레이터를 개발 주제로 선정하였다.

3. ChatGPT를 활용하여 3상 유도전동기의 기본 이론, 동기속도, 슬립, 토크-속도 곡선, 회전자계 형성 원리 등을 정리하였다.

4. 사용자가 원하는 프로그램 구조를 직접 정리하였다. 단순 공식 계산기가 아니라 제어반, 시각화 모델, 그래프, 경고판이 포함된 교육용 시뮬레이터 형태로 개발 방향을 설정하였다.

5. Codex를 활용하여 React + Vite 기반의 웹 애플리케이션 기본 구조를 생성하였다.

6. 3상 유도전동기의 동기속도, 회전자속도, 슬립, 전자기 토크 계산식을 코드로 구현하였다.

7. 토크-속도 곡선을 구현하고, 부하토크와 전동기 토크가 만나는 운전점을 자동으로 표시하도록 개선하였다.

8. SVG를 활용하여 3상 회전자계와 전동기 단면 시각화를 구현하였다.

9. 전동기의 구조를 더 직관적으로 보여주기 위해 3D 느낌의 전동기 모델을 추가하였다.

10. 실제 산업 현장의 전동기 제어반 느낌을 반영하여 START, RESET, EMERGENCY STOP 버튼과 RUN, STARTING, STOP 상태 표시등을 구현하였다.

11. 전동기 기동 과정을 시뮬레이션하기 위해 회전자 속도, 슬립, 전자기 토크가 시간에 따라 변하는 기동 특성 그래프를 추가하였다.

12. 3상 전류 파형 그래프를 추가하여 A상, B상, C상 전류가 서로 120도 위상차를 갖는다는 점을 시각적으로 확인할 수 있도록 하였다.

13. 운전조건 프리셋 기능을 추가하여 무부하, 정격부하, 과부하, 저전압, 고슬립 등의 조건을 빠르게 적용할 수 있도록 하였다.

14. 처음에는 프리셋을 선택하면 모터가 자동으로 기동되는 문제가 있었으나, 실제 제어반 동작에 맞게 프리셋은 입력값만 변경하고 전동기 기동은 START 버튼으로만 이루어지도록 수정하였다.

15. STOP 상태에서도 회전자계 화살표가 계속 회전하는 문제가 있었으나, 이론적으로 정지 상태에서는 고정자 전원이 차단되어 회전자계가 존재하지 않으므로 STOP, RESET, EMERGENCY STOP 상태에서는 회전자계가 OFF되도록 수정하였다.

16. STOP 상태에서 슬립이 100%로 표시되는 문제가 있었으나, 회전자계가 없는 상태에서는 슬립이 물리적으로 정의되지 않으므로 N/A로 표시하도록 수정하였다.

17. 기동토크가 부하토크보다 작을 경우 정상적인 기동이 어렵다는 점을 반영하여 기동토크 부족 경고를 추가하였다.

18. 주파수 변화가 리액턴스에 영향을 줄 수 있다는 점을 고려하여 주파수에 따른 리액턴스 보정 기능을 추가하였다.

19. 기동 중, 정상 운전 중, 비상정지 중 상태에 따라 회전자계, 회전자 속도, 전류 파형, 슬립 표시가 다르게 동작하도록 반복적으로 수정하였다.

20. 최종적으로 사용자가 전기전자 이론과 시뮬레이션 목적에 맞게 기능을 검토하고, AI는 구현 속도를 높이고 오류를 수정하는 도구로 활용하였다.

## 6. 실행 방법

본 프로젝트는 **React + Vite 기반 웹 애플리케이션**이다.  
GitHub 저장소에는 용량이 큰 `node_modules` 폴더를 포함하지 않았다.

`node_modules`는 실행에 필요한 외부 라이브러리들이 설치되는 폴더이며, `package.json`과 `package-lock.json`을 이용하여 동일한 환경으로 다시 설치할 수 있다.

따라서 처음 실행하는 사용자는 아래 순서대로 진행하면 된다.

---

### 6.1 사전 준비

이 프로젝트를 실행하려면 컴퓨터에 **Node.js**가 설치되어 있어야 한다.

설치 여부는 터미널에서 아래 명령어로 확인할 수 있다.

```bash
node -v
```

```bash
npm -v
```

버전 숫자가 출력되면 Node.js와 npm이 정상적으로 설치된 것이다.

예시:

```text
v24.5.0
11.12.1
```

만약 `node` 또는 `npm`이 인식되지 않는다면, Node.js LTS 버전을 설치한 뒤 다시 실행해야 한다.

---

### 6.2 GitHub에서 프로젝트 다운로드

1. GitHub 저장소 페이지에 접속한다.

```text
https://github.com/Gnho-UOU/motor-analyzer
```

2. 오른쪽 위의 초록색 **Code** 버튼을 클릭한다.

3. **Download ZIP**을 클릭하여 프로젝트 파일을 다운로드한다.

4. 다운로드한 ZIP 파일의 압축을 해제한다.

5. 압축을 해제하면 보통 다음과 같은 폴더가 생성된다.

```text
motor-analyzer-main
```

---

### 6.3 VS Code에서 프로젝트 열기

1. Visual Studio Code를 실행한다.

2. 상단 메뉴에서 다음을 선택한다.

```text
File → Open Folder
```

3. 압축을 해제한 프로젝트 폴더를 선택한다.

```text
motor-analyzer-main
```

4. 폴더가 열리면 VS Code 왼쪽 파일 목록에 다음과 같은 파일들이 보여야 한다.

```text
src
public
package.json
package-lock.json
README.md
vite.config.js
```

---

### 6.4 터미널 열기

VS Code 상단 메뉴에서 다음을 선택한다.

```text
Terminal → New Terminal
```

또는 단축키를 사용할 수 있다.

```text
Ctrl + `
```

터미널이 열리면 현재 위치가 프로젝트 폴더인지 확인한다.

예시:

```text
PS C:\Users\사용자이름\Downloads\motor-analyzer-main>
```

만약 프로젝트 폴더가 아니라면 `cd` 명령어로 프로젝트 폴더로 이동한다.

예시:

```bash
cd C:\Users\사용자이름\Downloads\motor-analyzer-main
```

---

### 6.5 필요한 패키지 설치

처음 실행할 때는 아래 명령어를 입력하여 필요한 라이브러리를 설치한다.

```bash
npm install
```

이 명령어를 실행하면 `package.json`과 `package-lock.json`에 기록된 정보를 바탕으로 필요한 패키지들이 자동으로 설치되고, `node_modules` 폴더가 생성된다.

설치가 정상적으로 끝나면 다음과 비슷한 메시지가 출력된다.

```text
added packages
found 0 vulnerabilities
```

---

### 6.6 개발 서버 실행

패키지 설치가 끝나면 아래 명령어를 입력한다.

```bash
npm run dev
```

정상적으로 실행되면 터미널에 다음과 비슷한 주소가 표시된다.

```text
VITE ready

Local: http://localhost:5173/
```

브라우저에서 해당 주소로 접속하면 MotorAnalyzer 시뮬레이터를 실행할 수 있다.

```text
http://localhost:5173/
```

---

### 6.7 포트 번호가 다른 경우

만약 `5173` 포트가 이미 사용 중이면 Vite가 자동으로 다른 포트를 사용할 수 있다.

예시:

```text
Port 5173 is in use, trying another one...

Local: http://localhost:5174/
```

이 경우에는 `5173`이 아니라 터미널에 표시된 주소로 접속하면 된다.

```text
http://localhost:5174/
```

---

### 6.8 실행 종료 방법

시뮬레이터 실행을 종료하려면 VS Code 터미널에서 다음 키를 누른다.

```text
Ctrl + C
```

종료 여부를 묻는 메시지가 나오면 `Y`를 입력하고 Enter를 누른다.

---

### 6.9 이후 다시 실행하는 방법

한 번 `npm install`을 실행한 뒤에는 매번 다시 설치할 필요가 없다.

다음부터는 프로젝트 폴더에서 아래 명령어만 실행하면 된다.

```bash
npm run dev
```

단, `node_modules` 폴더를 삭제했거나 다른 컴퓨터에서 처음 실행하는 경우에는 다시 아래 명령어를 먼저 실행해야 한다.

```bash
npm install
```

이후 다시 실행할 때:
